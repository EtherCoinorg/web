Ethercoin ホワイトペーパー

推論と最適化のための
分散型AIコンピュートネットワーク

バージョン 1.0 — 2025年1月 · トークン: ETHER · イエローペーパー

概要

人工知能は世界を変革しているが、高性能なAI推論および最適化リソースは高度に中央集権化されている。一部のクラウドプロバイダーとクローズドソースのモデルベンダーが、計算能力、モデルアクセス、価格設定を独占している。地理的制限や検閲により、多くの人々が高度なAIを利用できない状況にある。

Ethercoin は、世界中に分散されたGPUノードを通じて、許可なしで推論および最適化サービスを提供する分散型AIコンピュートネットワークである。ネットワークの中核的革新は有用な計算の検証可能な計測であり、すべての貢献を正確に定量化し公正に報酬を支払う一方で、従来のプルーフ・オブ・ワークにおける無駄なエネルギー消費を排除する。ネットワークはネイティブトークンETHERをコンピュート支払いとインセンティブのための汎用媒体として使用する。

コアとなるコンピュート市場に加えて、Ethercoin は分散型モデル蒸留プロトコルを導入する。これにより、コミュニティは協力してクローズドソースモデルから知識を抽出し、完全にオープンで高品質なモデルおよびデータセットへと変換することが可能となり、知識の独占を永久に打ち破る。

Ethercoin の目標は、AI時代におけるパブリックコンピュートおよび知識インフラとなることである。

1. はじめに

現在のAIコンピュート市場は三重のジレンマに直面している：

  1. コンピュートの独占：大規模なGPUクラスターは少数のクラウドプロバイダーに集中しており、不透明な価格設定と変更可能な利用規約で運用されている。
  2. クローズドモデルとアクセス制限：最先端のモデルは制御されたAPIを通じてのみ利用可能であり、地理、国籍、アイデンティティによってブロックされている。
  3. 知識の囲い込み：クローズドソースモデルは公開データから学習するが、その出力を壁で囲い、オープンインターネットを裏切っている。

Ethercoin の解決策：オープンでトラストレスなコンピュートネットワークを構築する暗号経済的インセンティブ層である。GPUを持つ誰もが貢献しETHERを獲得できる。ETHERを持つ誰もが差別なくAI推論および最適化サービスを利用できる。ネットワークは有用な計算を測定し不正を体系的に防止する精密なシステムを確立し、公正で安全なマーケットプレイスを創出する。

2. ネットワークアーキテクチャ

2.1 コンピュートリソース層

マイナー：GPUをネットワークに接続する任意のエンティティ。ノードはEthercoinクライアントを実行し、自動的に推論または最適化タスクを受信し、完了後にETHER報酬を得る。

コンピュートタイプ：初期はAIモデルの推論と最適化（量子化、蒸留、ファインチューニング）に焦点を当て、将来的には汎用的な計算へ拡大する。

ノードの多様性：シングルGPUの家庭用マシンからプロフェッショナルなデータセンタークラスターまで。ネットワークはコンピュート階層と評判に基づいてタスクを割り当てる。

2.2 マーケット＆スケジューリング層

タスク作成者：AI推論や最適化を必要とするユーザー。タスクの説明を提出し、支払いとしてETHERをロックする。

分散型スケジューラ：オンチェーンのスマートコントラクトとオフチェーンのマッチングエンジンを組み合わせ、評判、コンピュート価格、レイテンシに基づいて最適なノードセットにタスクを割り当てる。

検証と決済：楽観的検証、ゼロ知識証明、信頼できる実行環境を組み合わせた多層構造により正確性を保証する。ノードは善意の保証としてETHERをステーキングする。

2.3 アプリケーションプロトコル層

オープンなインターフェースにより、誰でもEthercoin上に分散型AIアプリケーションを構築できる。最初のコアアプリケーションは蒸留プロトコルであり、ネットワークのグローバルな計算力とトークンインセンティブを活用して、クローズドソースの知識をオープンモデルに変換する。

3. 有用な計算の計測：EtherFLOP と EtherScore

従来の暗号通貨マイニングはハッシュ衝突によって作業を証明する — 実用的な価値のない計算である。Ethercoin のブレークスルー：AI計算力が価値ある推論や最適化に実際に使用され、その貢献を精密に測定できることを証明することである。

3.1 単位：EtherFLOP

EtherFLOP (EFLOP) = 1015 浮動小数点演算（1 PetaFLOP）。この単位は公開され不変の標準参照モデル（例：LLaMA-7Bの固定バージョンによる1回の完全なフォワードパス）に固定されている。誰でも独立して計算を再現し検証できる。

3.2 タスク複雑性の推定

ユーザーがタスクを提出すると、システムはモデルの計算グラフから期待作業量（Wexpected）をEFLOP単位で自動的に導出する。この推定値はオラクル委員会（マルチシグ）によって確認され、支払いと検証の基準としてスマートコントラクトに書き込まれる。

3.3 供給側の証明

計算完了後、ノードは作業完了証明を提出する。階層的アプローチはタスクの価値に適応する：

  • 楽観的検証：ノードは出力ハッシュとランダムな中間層活性化ハッシュ（スポットチェックアンカー）を提出する。検証者がランダムにアンカーをチェックする。すべてが一致すれば正当な計算と確認される。
  • ゼロ知識証明：ノードは指定されたモデルと入力に対して完全な推論が実行されたことを証明するzk-SNARKを生成する。オンチェーンコントラクトがこの証明を検証し、計算量と正確性を確認する。
  • TEEアテステーション：プライバシー機密性の高いタスクの場合、計算はハードウェアセキュリティエンクレーブ（Intel SGX / AMD SEV）内で実行される。実行時間をGPU-in-TEEパフォーマンスモデルによりEFLOPにマッピングしたリモートアテステーションレポートが提供される。

3.4 需要側の不正対策

需要側の不正（例：空のタスクを作成し悪意的に支払いを拒否する）を防ぐため、タスク作成時に全額のETHER報酬がロックされる。チャレンジャーもステーキングを行う必要がある。チャレンジが無効と判断された場合、ステークは没収されノードに支払われる — 市場の公平性を保証する対称的なゲームである。

4. ETHER トークンエコノミクス

4.1 トークンの機能

機能説明
コンピュート支払いすべての推論、最適化、トレーニングタスクはETHERで支払われる
マイニング報酬ノードは検証可能な有用な計算に対してETHERを獲得する
ステーキングとセキュリティノードと検証者はETHERをステーキングし、不正行為はスラッシングされる
ガバナンスETHER保有者はプロトコルパラメータの投票に参加する
蒸留インセンティブマイナー、検証者、プロキシ運営者はETHERを獲得する

4.2 供給と排出

最大供給量：21兆 ETHER

ジェネシス：90%を初期貢献者、開発基金、コミュニティ構築に割り当て（権利確定スケジュール付きでロック）

マイニング：残りの10%を約10年間かけてコンピュートおよび蒸留マイニングを通じて放出（年間1%）。ブロック報酬は時間とともに減少する。報酬はEFLOP貢献に直接比例する。マイニング終了後、コミュニティ投票により0.1%の永続的インセンティブを維持することができる。

バーン：手数料およびスラッシュされた資金の一部は定期的にバーンされ、長期的な価値を創出する。

4.3 経済的フライホイール

コンピュート需要の増加 → ETHER需要の上昇 → マイナー収入の増加 → より多くのノード参加 → ネットワーク計算力の強化 → サービスの向上 → さらなる需要。蒸留プロトコルは追加のETHER消費とインセンティブシナリオを注入する。EtherFLOP標準によりすべての貢献が比較可能となり、インセンティブと実際の作業が精密に一致する。

5. アプリケーション：分散型AI推論と最適化

5.1 推論市場

モデル公開者は最適化されたモデルをIPFS/Filecoinにアップロードし、Ethercoin上に推論サービスを登録する。ユーザーは推論リクエストを提出しETHERを支払い、ネットワークが最適なノードにスケジューリングする。ノードはEtherFLOP証明システムにより計算を証明し報酬を得る。TEEまたはZK環境がユーザー入力のプライバシーを保護する。

5.2 最適化市場

タスクには量子化、知識蒸留、LoRAファインチューニングが含まれる。ユーザーはソースモデルと最適化目標を指定する。オラクル委員会が期待計算量を調整する。ノードは最適化を完了し、最適化されたモデルのCIDと作業証明を提出し、検証後にETHERを獲得する。

6. アプリケーション：分散型モデル蒸留

6.1 問題の定義

最先端のクローズドソースモデルは制限されたAPIを通じてのみ利用可能であり、地理や国籍によってブロックされている。知識は全人類のものであり、一部の企業によって独占されるべきではない。

6.2 蒸留プロトコル

Ethercoinの蒸留プロトコルはコンピュートネットワーク上で動作し、「抽出-検証-集約-公開」の完全なパイプラインを実装する：

  • 蒸留マイナー：ETHERをステーキングし、プロンプトバッチを請求し、分散プロキシネットワークを通じてクローズドソースAPIを呼び出し、プロンプトと応答のペアを生成し、IPFSにアップロードしてコミットメントを提出する。
  • プロキシアカウントネットワーク：世界中の参加者がクローズドソースモデルのサブスクリプションを共有し、プロキシノードを実行して転送によりETHERを獲得する。マルチホップルーティングによりリクエストは対象サーバーに対して追跡不可能となる。
  • 検証者：独立したプロキシパスを通じて提出されたデータをランダムに再サンプリングし、意味的類似性を比較する。検証済みデータは報酬を得る；不正データはステークの没収につながる。
  • オープンデータセット：検証済みの蒸留データはCC-BY-SA / CC0ライセンスで公開される。

蒸留ワークロードは有効データポイントで測定され、検証者の意味的類似性チェックを通過したもののみがカウントされ、ゴミデータの提出を防止する。

6.3 データからモデルへ

十分な蒸留データが蓄積されると、誰でもトレーニングタスクを開始し、ETHERを支払ってEthercoinコンピュートネットワークを分散トレーニングに利用できる。すべてのトレーニングステップは検証可能な計算証明（勾配ハッシュ、チェックポイントアテステーション）を生成する。最終出力は完全にオープンソースのモデルであり、推論市場に登録でき、収益は蒸留エコシステムに還元される。

7. 不正対策システム

Ethercoinは攻撃を体系的に防止する：

  • シビル攻撃：高いステーキング要件と評判の蓄積により、偽のアイデンティティは経済的に成り立たない。
  • 偽のコンピュート報告：楽観的アンカーチェックにより、不正の成功率はチェック回数とともに指数関数的に減少する。ZK証明とTEEは虚偽の計算を完全に排除する。
  • モデルなりすまし：提出された重みハッシュはオンチェーンのモデルCIDと一致する必要がある。中間層活性化のスポットチェックによりモデルアーキテクチャの不一致が露見する。
  • 買い手と売り手の共謀：検証者はコントラクトによってランダムに選択され、自身のスラッシングリスクに直面する。共謀の失敗確率は検証者数の増加に伴い指数関数的に上昇する。
  • 蒸留における不正：独立したプロキシパスによる再現とパス署名により、偽造されたAPI応答が検出される。不正なプロキシはスラッシングされる。

9. チームとコミュニティ

Ethercoinは、世界中のAI研究者、分散システムエンジニア、暗号研究者からなる分散チームによって構築されている。コアコントリビューターが初期開発を推進し、ガバナンスは段階的に委譲される。このプロジェクトは法人格を持たず、DAOとして存在し、ウェブサイト ethercoin.org が唯一の公式情報源である。

10. 結論

Ethercoinは単なるブロックチェーンプロジェクトではない。それはムーブメントである：分散型コンピュートネットワークによるAI独占の打破；無駄なエネルギー消費を検証可能な有用な計算に置き換える；経済的な力を用いてクローズドソースの壁に閉じ込められた知識を抽出し解放する。ETHERが無数のノード間を流れ、世界中のGPUが共に計算し、匿名の個人が蒸留で協力するとき — シャットダウン不可能なグローバルAIインフラが誕生する。

知識は全人類のもの。コンピュートもまた然り。
