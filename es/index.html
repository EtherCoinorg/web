¿Qué es Ethercoin?

El poder de cómputo de IA está concentrado en manos de unos pocos proveedores en la nube. Ethercoin rompe este monopolio.

Ethercoin es una red de cómputo de IA descentralizada donde cualquiera con una GPU puede contribuir con poder de cómputo y ganar ETHER. Cualquier persona que posea ETHER puede acceder a servicios de inferencia y optimización de IA sin permisos, censura ni restricciones geográficas.

La red mide la «computación útil» a través de un sistema de prueba verificable llamado EtherFLOP — garantizando que cada operación de IA sea real y recompensada con precisión. Sin minería derrochadora — cada vatio alimenta cargas de trabajo reales de IA.

Más allá del cómputo, Ethercoin alberga el Protocolo de Destilación Descentralizado, un sistema revolucionario que extrae conocimiento de modelos de IA de código cerrado y lo libera como bienes públicos abiertos. El conocimiento pertenece a la humanidad.

Tecnología Principal

Cada componente está diseñado para la verificabilidad, la resistencia a la censura y los incentivos justos.

⚠

Cómputo Verificable

EtherFLOP mide con precisión el trabajo útil de IA. Un sistema de verificación de tres capas — comprobaciones optimistas, pruebas de conocimiento cero y atestaciones TEE — garantiza que cada EFLOP sea real.

🔗

Verificación en Capas

Las tareas de bajo valor usan verificación optimista rápida con comprobaciones aleatorias. Las tareas de alto valor usan pruebas ZK o atestación remota TEE. El costo escala con el valor de la tarea.

🚪

Anticensura

La red proxy enrutada con cebolla distribuye las llamadas API entre nodos globales, haciendo las solicitudes imposibles de rastrear. Sin un único punto de bloqueo o control.

⚡

Protocolo de Destilación

Extrae conocimiento de modelos de código cerrado a través de una red descentralizada de mineros, nodos proxy y verificadores. El resultado son datos abiertos con licencia CC.

💰

Seguridad Basada en Apuestas

Todos los participantes — mineros, verificadores, nodos proxy y retadores — apuestan ETHER. El comportamiento deshonesto resulta en penalizaciones, haciendo que los ataques sean económicamente irracionales.

📈

Reputación en Cadena

Cada nodo construye un historial verificable de tareas completadas, tiempos de respuesta y precisión. Los nodos con alta reputación obtienen mejores asignaciones de tareas.

Cómo Funciona

Desde la creación de la tarea hasta el resultado verificado — un ciclo de vida completo en la red Ethercoin.

1

Crear una Tarea

Envía un CID de modelo, datos de entrada y EFLOPs esperados. Bloquea ETHER como pago y apuesta de desafío. Elige el modo de verificación: optimista, ZK o TEE.

2

Emparejar y Ejecutar

El planificador descentralizado empareja tu tarea con el mejor nodo GPU según reputación, latencia y apuesta. El nodo ejecuta la carga de trabajo de inferencia u optimización.

3

Verificar y Liquidar

El nodo envía una WorkProof con hashes de anclaje o prueba ZK. Los verificadores comprueban la corrección durante el período de desafío. Las recompensas se liberan tras la verificación.

4

Destilar y Abrir

Para tareas de destilación, los datos verificados pasan controles de similitud y se publican como conjuntos de datos de código abierto. El conocimiento fluye libremente para todos.

FAQ

Respuestas rápidas a preguntas frecuentes.

¿Qué hace diferente a Ethercoin de otros proyectos cripto de IA?

Ethercoin se centra en cómputo útil verificable — cada EFLOP se mide y verifica a través de un sistema de pruebas en capas, no auto-reportado. El protocolo de destilación es una aplicación única que convierte el conocimiento de código cerrado en bienes públicos abiertos.

¿Cómo se verifica el cómputo sin terceros de confianza?

Tres modos de verificación: comprobaciones optimistas (activaciones aleatorias de capas), pruebas de conocimiento cero (zk-SNARKs) y atestaciones remotas TEE. Cada modo se adapta a diferentes valores de tarea y requisitos de privacidad.

¿Puede cualquiera participar en el protocolo de destilación?

Sí. Los mineros GPU procesan tareas de destilación. Los operadores proxy comparten acceso a la API a través de una red enrutada con cebolla. Los verificadores validan los datos enviados. Todos los participantes apuestan ETHER y ganan recompensas.

¿Cuándo se lanzará la mainnet?

La Fase 1 (Génesis) se lanza en el Q3–Q4 de 2026, con soporte para tareas de inferencia, minería y la versión beta del protocolo de destilación. Consulta la hoja de ruta en el whitepaper para más detalles.
